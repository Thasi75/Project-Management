# FDE交付工作台

依据已确认的《开发方案 V1.3》实现的 Windows 本机单人管理应用。React + TypeScript 前端由 FastAPI 托管，SQLite 保存多项目数据，附件保存在本机。

界面采用深蓝主色、白色内容区和深灰文字，表头使用灰蓝底与加粗深色文字，日期、责任人及说明统一加深。甘特图任务条按状态区分：未开始为灰色、进行中为蓝色、暂停为深橙色、已完成为深绿色，已取消仍为灰色，实际进度为深灰细条，“今天”以加粗虚线标识；保留文字状态及悬停详情。全局配色统一维护于 `frontend/src/style.css`，没有单独的汇报模式。

## 启动

双击项目根目录的 **启动.cmd**。当前环境的依赖和前端构建产物已经准备好。浏览器会在服务就绪后打开 [FDE交付工作台](http://127.0.0.1:18765)。保留启动窗口，关闭时按 `Ctrl+C`。

也可以在 PowerShell 中执行：

```powershell
.\start.ps1
# 如果端口已被其他应用占用
.\start.ps1 -Port 18766
# 不自动打开浏览器
.\start.ps1 -NoBrowser
```

首次在其他电脑部署需安装 Python 3.12+；重新构建前端还需 Node.js 22.12+ 和 pnpm。启动脚本会在缺少 `.venv` 时按 `requirements.txt` 安装固定版本的 Python 依赖。服务只绑定 `127.0.0.1`，单进程运行；不要使用多个 uvicorn worker。

## 开始使用

1. 点击顶部右上角的“新建项目”，填写项目名称和范围。保存后自动切换到新项目 Tab。可批量上传附件；每个文件单独显示结果，失败后可重试。
2. 在“项目概况”的“人员资料”中登记本项目人员，全部人员在同一个网格连续排列，宽屏每行显示 6 列，不显示单位/团队分组标题，不因单位不同而另起一行；卡片仍显示单位/团队，窄屏自动减少列数；可填写单位/团队、备注和启用状态；然后通过“编辑项目”指定负责人。所有人员下拉、多选、主持人/记录人单选及筛选列表均按单位/团队分组，未填写单位的人员归入末尾的“未填写单位 / 团队”组。每个项目的资料独立维护，任务、日志、风险等人员选择及筛选仅使用本项目人员。停用后不能新增选择，原有引用仍保留；归档项目只读。“设置与维护”仅保留系统配置和备份恢复。
3. 在“项目概况”中查看客户名称、项目范围、负责人和工期，以及已上传的项目附件和已登记的功能模块。附件大小显示在文件名后，间隔一个汉字宽度，说明随后同排展示；附件行高与功能模块一致，超长内容可悬停查看全文；可直接下载，已移除附件不展示；模块以三列展示，仅显示模块名称；“项目公共事务”固定为第一项并使用蓝色文字，其余保持登记排序，维护后自动同步。项目状态、项目编号和范围版本紧邻“项目概况”标题右侧；标题行最右侧一行展示编辑项目、范围版本、项目附件、功能模块、归档或恢复项目按钮。每个项目自带“项目公共事务”。新建功能模块支持“保存并继续新增”：保存后保留窗口，清空名称、排序加 1，保留启用状态并聚焦名称；普通“保存”仍保存并关闭。
4. 新建任务，填写计划日期、交付物和责任人。在任务编辑中登记执行、暂停、完成或取消；状态与日期变更需写原因。
5. 在“项目沟通”登记交流情况，保存后自动生成工作日志；也可直接登记工作日志（功能模块选填）及需求变更。日志不会自动改变任务；变更不设置审批或业务状态，也不会自动改变范围和排期。
6. 选择简报独立日期范围，先预览取数，再调用 OpenAI。成功后直接查看排版后的正式正文，可点击“编辑正文”修改并保存新版本，导出 Word/PDF。

项目 Tab 与系统名称位于同一标题栏，紧邻系统名称右侧，默认选中第一个可见项目；项目名称完整显示，不换行，项目较多时可横向滚动，也可用方向键及 Home/End 切换。“显示归档项目”位于顶部“新建项目”按钮之前，默认勾选；取消勾选仅显示未归档项目，若当前项目被隐藏则选中第一个可见项目，没有可见项目时显示空状态。新建项目和设置与维护按钮仍位于标题栏右侧。

标题栏下直接展示指标卡片，不再重复显示日期、工作空间名称、项目名称和客户标题。指标依次为项目进度、任务总数、已完成任务、未开始任务、逾期任务、未关闭风险、累计需求变更、未上线接口、项目直接成本；“未开始任务”统计当前项目未移除且状态为“未开始”的全部任务，包含未来计划，不受列表筛选和分页影响。“未上线接口”统计当前项目未移除、接口标记为是且状态不等于“上线”的外部接口记录数，不受列表筛选或分页影响；在需求调研或外部接口保存状态后自动刷新。指标卡片保持紧凑高度并在一行展示，空间不足时可横向浏览。全部指标卡片支持点击及键盘激活：项目进度进入全部任务甘特图、任务总数进入全部任务列表，已完成/未开始/逾期任务进入对应条件的任务列表，未关闭风险进入未关闭风险列表，累计需求变更进入全部需求变更，未上线接口进入状态不等于上线的外部接口，项目直接成本进入全部费用。每次点击清空目标列表旧筛选并回到第一页，项目进度显示甘特图，其他任务指标显示列表，均取消分组；筛选栏显示对应条件，支持继续筛选和重置。项目进度仍按计划天数计算，不等同于列表记录数。点击后的来源卡片保持深蓝高亮，翻页和视图切换保留；手动修改对应列表的关键词、状态、人员、日期等筛选或点击重置后取消高亮，手动切换左侧功能会清除来源高亮；从菜单进入任务计划、项目风险、需求变更、外部接口、成本管理时，清空目标列表筛选和关键词、回到第一页显示全部记录。返回原功能不恢复指标筛选或高亮，只有再次点击指标卡片才按指标口径筛选并重新高亮。切换项目也清除来源标记。

功能导航改为可完全隐藏的左侧栏，依次为项目概况、任务计划、需求调研、外部接口、项目沟通、工作日志、配置管理、需求变更、项目风险、项目简报、验收材料、成本管理。默认选中任务计划，切换项目时也回到任务计划；各功能保留筛选及页面状态。侧栏默认隐藏，点击系统名称与项目 Tab 之间的唯一导航图标展开或隐藏，并在当前浏览器记住状态。侧栏与标题栏的系统名称区域共用左边距和192像素宽度，左右边缘对齐。窗口宽度达到 1740 像素时，侧栏与工作区并排，指标卡片和各功能区域占满侧栏右侧可用宽度，侧栏与内容间距32像素，页面右边距24像素；不再限制列表为1400像素宽。隐藏侧栏时工作区继续扩展到可用宽度。较窄窗口采用覆盖式侧栏，不压缩列表，点击功能、遮罩、顶部导航图标或按 Esc 关闭；支持上下方向键及 Home/End 切换功能。


需求调研位于任务计划之后、外部接口之前。序号在首位，默认填写本项目下一个序号，可手工修改为正整数；列表和 Excel 按序号从小到大排序。同号按日期、创建时间和 ID 稳定排序。表单第一行依次为序号、日期、功能模块、接口、对接系统；接口通过开关选择是/否，默认否，为是时对接系统必填，为否时可选填且关闭开关不清空已有内容。历史记录缺少这两个字段时按否/空显示，不改写原记录。日期默认当天；功能模块、需求来源、记录人从本项目资料单选；重要性默认“中”，是否响应默认“是”，状态默认“设计”，其余可选值分别为高/低、否、开发/上线。接口记录另提供上线日期，状态为上线时必填。除备注、条件必填的对接系统和上线日期外，其余字段均须有值；需求描述、解决思路、备注保留多行。支持关键词、模块、需求来源、记录人、状态和接口筛选，接口提供全部接口/是/否，界面不再提供日期范围筛选。关键词也可查找对接系统。列表及 Excel 在需求描述之后依次显示接口、对接系统。支持编辑、修订记录和移除；编辑窗口右下角的“上一条”“下一条”按当前筛选和列表顺序切换，支持跨页；有未保存修改时先显示系统内确认提示，首尾按钮自动禁用。“导出 Excel”导出当前筛选下全部调研记录，不限当前页；归档项目可查看与导出。

外部接口自动展示当前项目需求调研中接口为“是”且未移除的记录，按序号排序；两处共用记录，不重复登记。列表字段依次为序号、对接系统、需求描述、解决思路、需求来源、状态、开发情况、上线日期，末列提供编辑。仅状态、开发情况（多行文本）和上线日期可编辑；其余字段采用浅灰背景、正常深色文字，禁止修改。状态沿用设计/开发/上线，为上线时日期必填且不能晚于今天，两处状态同步；普通调研修改不会清空已登记的开发情况。取消接口标记或移除调研后同步隐藏，保留已有详情。编辑窗口“查看原始需求”打开对应调研，未保存修改先由系统内提示确认；归档项目均只读。支持关键词、需求来源和状态筛选，外部接口不纳入简报素材来源。

新建需求调研支持“保存并继续新增”：保存后窗口保持打开，保留日期、功能模块、需求来源和记录人；需求描述、解决思路、备注和对接系统清空，接口恢复为否，重要性/是否响应/状态恢复为中/是/设计，焦点回到需求描述。序号重新获取本项目最大已用序号加一，可手工修改；读取失败时可手工填写继续。每条独立保存，普通“保存”仍保存并关闭；编辑和只读窗口不提供连续新增。

需求调研筛选区的功能模块后提供“需求来源”和“记录人”两个单选条件，默认分别为全部需求来源、全部记录人。选项只取当前项目人员并按单位/团队分组，停用人员仍可用于查询历史记录；两项可与其他筛选组合使用，切换条件回到第一页，重置清空全部条件。Excel 导出及编辑窗口上一条/下一条均沿用当前筛选范围。

需求调研、外部接口、任务计划列表视图、项目沟通、工作日志、配置管理、需求变更、项目风险、验收材料和成本管理的表格，垂直滚动仅作用于数据行区域；表头、标题、筛选和按钮保持固定，分页固定在数据区下方。横向滚动时表头与数据同步对齐；窄窗口中指标卡片改为一行横向浏览，以保留数据区高度。项目概况、简报及甘特图沿用各自原有滚动方式。

任务计划标题后提供全屏图标，点击后仅任务计划容器铺满屏幕，保留筛选、视图切换和任务登记；点击退出图标或按 Esc 恢复，筛选、分页和时间尺度保持。浏览器不支持原生全屏时铺满当前页面。任务列表可按状态、人员、模块、阶段及关键词筛选；“列表分组”位于筛选条件与日／周／月切换之间，可按阶段或模块分组，选择分组后切换到列表。“日／周／月”位于任务标题操作区、“甘特图／列表”切换左侧，仅在甘特图视图显示，来回切换视图保留当前尺度；甘特图与列表共用当前筛选和分页，任务按计划开始日期从早到晚排序后再分页（同日按创建时间升序、ID 稳定排序）；甘特图的任务名与责任人在一行显示，责任人位于任务名之后，字号保持不变，长文本可悬停查看完整内容。项目、任务、日志及变更在弹窗中编辑，不离开单页工作台。简报支持全屏编辑。

合并后的系统标题栏和指标卡片固定在上方，取消独立项目 Tab 行和横向功能 Tab 行，为列表增加可视高度。侧栏独立滚动；业务滚动条不覆盖标题栏、指标卡片及表格标题、筛选和表头。切换功能时内容区回到顶部，上方区域保持固定。

项目进度 = 已完成任务的计划天数之和 / 全部任务的计划天数之和 × 100%，四舍五入为整数。每项计划天数按结束日期减开始日期再加 1 计算，含首尾日期和周末；重叠任务分别累加，已取消任务计入分母，已移除任务不计入。无任务显示 0%，不受列表筛选、分页或分组影响。工作台不再展示原任务完成率、说明及图例行。

“验收材料”位于成本管理之前，可集中上传、预览、下载、编辑附件说明。列表依次显示附件名称、材料说明、上传时间、验收材料和操作；材料说明独立成列，支持换行，未填写时显示“—”。支持图片（PNG/JPG/JPEG/GIF/WebP）、PDF、Word（DOC/DOCX）、表格（XLS/XLSX/CSV），继续遵守设置中的文件类型白名单和大小限制。从此 Tab 上传会自动标记为验收材料；其他上传入口默认关闭。项目概况、附件管理、任务/需求变更关联列表和上传结果中均有“验收材料”开关，打开后同步出现在验收材料列表。两个入口共用同一个附件 ID 和文件，关闭开关仅取消验收用途，原文件及业务关联仍保留。每行“预览”在系统弹窗中显示附件，支持全屏查看和下载原文件。图片、PDF 直接显示，Word、Excel 及已有演示文稿由本机 LibreOffice 转为 PDF，首次预览可能需要一些时间；CSV 以表格显示（最多 1000 行、100 列，超过时提示下载），TXT/MD 以纯文本显示，文本预览上限 2 MB。不支持、缺失、加密或损坏时在弹窗提示并可重试、下载。预览不改变原附件或业务数据，可重建缓存位于 `data/previews/`，不进入业务备份。归档项目只读；已移除附件不显示，恢复后沿用原标记。历史附件升级后默认不标记为验收材料。

“项目沟通”位于任务计划与工作日志之间，登记时间（YYYY-MM-DD HH:MM:SS）、地点、主题、功能模块、参与人员、主持人、记录人、概况及详情。功能模块为必填，位于主题右侧同一行，选项来自本项目，默认“项目公共事务”。人员均从当前项目资料的分组下拉列表选择，参与人员可多选，主持人和记录人各单选一名，单位/团队分组与需求调研一致。可按关键词、主持人、日期筛选，按沟通时间从早到晚显示。

任务、项目沟通和工作日志的参与人员采用多选下拉框，收起时显示已选姓名及单位；展开后按单位/团队分组勾选，点击外部、按Esc、焦点移出或滚动表单时收起。已停用人员不可新增选择，旧引用可保留；沟通同步日志的参与人员及归档记录仍不可修改。需求变更的提出人/来源改为同样分组的单选下拉框，新选来源保存姓名及单位文字；历史自由文本放在“原有来源”选项中保留，可改选本项目人员或清空，原有修订和简报不变。

沟通保存后自动生成一条工作日志：日期取沟通日期，功能模块取沟通所选模块，责任人取主持人，参与人员、概况及详情分别对应日志参与人员、工作内容及工作详情。编辑沟通更新原日志，移除沟通同步移除日志，修订记录和已保存简报保留。对应日志通过来源按钮回到沟通修改同步字段；功能模块统一在沟通记录中修改；关联任务、后续安排和备注可在日志中补充，后续同步时保留。新简报通过该日志纳入沟通内容，不重复计数。

已保存沟通记录的编辑窗口提供“导出 Word”“导出 PDF”，归档项目的查看窗口也可导出。导出包含项目、主题、时间、地点、功能模块、参与人员（姓名及单位/团队）、主持人、记录人、沟通概况和完整详情，保留换行。使用已保存内容；有未保存修改时在窗口底部提示，需先保存再导出修改内容。新建记录保存后才提供导出。Word 使用 A4 中文排版，PDF 从同一份 Word 转换；转换组件不可用时明确提示，Word 可独立导出。导出文件按沟通内容、记录版本及当前人员/模块资料缓存，不写入业务数据或新增修订。

沟通概况和沟通详情可拖动文本框右下角分别调整高度。点击保存时按本条沟通记录记住两个高度，下次打开或刷新后仍恢复；取消修改则保留上次保存的高度。尚未保存高度的旧记录使用原默认高度。

“配置管理”位于工作日志与需求变更之间，用于登记当前项目的配置事项。“项目”用于手工登记配置项目名称（例如服务器IP），为必填单行文本；新建时为空，历史记录保留升级前显示的项目名称，可逐条修改。配置归属仍为当前项目，不可转移；配置信息和创建或变更日期为必填，备注选填；两个文本字段支持多行。日期默认今天，不得晚于今天。支持关键词和日期筛选、分页、编辑、软移除及修订记录，归档项目只读。简报按所选期间（包含首尾日）采集未移除配置记录，并在预览中显示数量；配置项目名称、完整配置信息与备注作为生成素材进入现有相关章节，已有简报快照及正文版本不受后续编辑影响。

“成本管理”位于功能 Tab 最后一项，登记当前项目直接费用。费用日期必填，默认今天，可修改为实际发生日期，不晚于今天；费用项目为必填单选：省际交通费、市内交通费、住宿费、业务招待费、Token、其他；金额必填，以元为单位，支持非负金额和最多两位小数，统一显示两位；备注为多行选填。表单的费用日期、费用项目、金额在同一行，备注另起一行；列表在费用项目之前显示费用日期，按费用日期从早到晚排列。旧备份中的费用没有日期时显示未登记，编辑时补填。支持按费用项目、备注关键词筛选，分页、编辑、软移除及修订记录，归档项目只读。顶部“项目直接成本”以元显示本项目所有未移除费用的合计，不受筛选或分页影响，修改或移除后同步更新；内部按整数分精确保存和汇总。费用记录及成本总额均不纳入项目简报的素材、统计或模型输入。

各功能 Tab 的日期列表统一从早到晚排序：任务按计划开始日、沟通按沟通时间、日志按工作日期、配置按创建或变更日期、变更按变更日期、风险按提出日期、费用按费用日期、验收材料按上传时间、简报按报告开始日和结束日。同日期再按录入时间升序，缺失费用日期排末尾；排序在分页之前进行，日志 Excel 导出与列表一致。

## 日期与历史

- 任务和日志业务日期精确到天，沟通时间精确到秒，按 Asia/Shanghai 保存和展示。
- 补录旧项目时，填写相应的“本次修订业务生效日”；范围版本按生效日选取。
- 任务执行开始和完成按实际日期记录；结束日在报告期之后的任务不会计入当期完成。
- 更正实际开始或完成日期会通过追加修订修正历史还原，不改写原审计记录。
- 经明确确认的误登记状态可通过追加历史更正撤销指定修订的业务效力，原始修订和旧简报快照继续保留，后续真实状态变化仍有效。
- “本期完成任务数”按期间完成事实的任务 ID 去重；任务完成后重新打开，完成记录仍保留，期末状态与本期完成分别展示并提示。
- 历史简报中的任务完成率为期末已完成 / 有效任务总数，有效任务排除已取消项；无有效任务显示“—”。不代表工作量比例。
- 新生成简报的项目进度按报告期末任务状态和计划日期计算，沿用工作台的计划天数加权公式；任务数量完成率仍单独保留，不替代项目进度。
- 已保存简报含独立输入快照；补录、更正和字典改名不会改变旧简报。重新生成读取最新修正后的事实并产生新版本。
- 长列表每页 20 条；列表分组和甘特图针对同一页记录。

工作日志列表依次显示工作日期、工作内容、模块 / 责任人、参与人员、关联任务、后续安排及操作。参与人员取当前项目人员姓名，多人以顿号分隔并支持换行，未登记显示“—”。

## 工作日志导出

工作日志标题右侧、“登记日志”左侧提供蓝色“导出 Excel”按钮。按当前已应用的关键词、功能模块、责任人、关联任务和日期条件导出全部匹配日志，不受当前分页限制；归档项目也可导出。未匹配到记录时导出仅含表头的文件。

导出包含日志编号、工作日期、功能模块、责任人、参与人员、关联任务、工作内容、工作详情、后续安排、备注及日志来源，保留完整文本与换行，并按列表相同顺序排列。文件包含项目名称、导出时间、筛选条件和记录数，提供冻结表头与筛选；工作日期为 Excel 日期单元格。

## OpenAI 设置

在“设置”中填写 OpenAI 模型和 API Key。默认模型为 `gpt-4.1-mini`，可替换为账户可用且支持 Responses API 结构化输出的模型。也支持后端环境变量 `OPENAI_API_KEY`（优先于本机保存值）。

API Key 使用 Windows DPAPI 按当前用户加密，保存于 `local/openai.key`；不回传前端、不写入日志、不进入项目备份。其他电脑或 Windows 用户需要重新配置密钥。环境变量中的密钥由运行应用的账户自行维护。

请通过当前 Windows 用户双击 `启动.cmd` 启动正式工作台。由 Codex 离线沙箱账户启动的服务只能访问本机，生成简报会遭遇系统网络权限拒绝；此时延长超时或重复生成无效。代理及 API Key 也与运行账户有关，切换账户后需重新配置密钥。程序分别提示网络权限阻止、连接失败和请求超时；这些失败均不覆盖已保存的正文。

生成使用 OpenAI 官方 SDK 的 Responses API，关闭服务端结果存储选项；资料仅作数据，不执行资料中的指令。程序预计算统计并在后台校验事实、章节和数字。单批材料直接生成正式正文；大量输入先分批整理，再整篇统稿，归并主题、去除重复、统一时态，保留每批事实并记录批次数。正文不展示来源编号、处理批次或模型说明，默认约 1200—2000 字，材料少时相应缩短。后台事实快照仍随版本保存。生成或统稿失败均不会覆盖已有正文，后台任务重启后标记可重试；单个任务最多尝试 3 次，认证错误需修正配置后重新生成。

未配置密钥或断网时，项目、任务、日志、变更、已有简报与备份仍可使用。真实 OpenAI 调用需用户配置有效凭据。自动化测试覆盖可控响应与失败场景；2026-11-25 已在当前 Windows 用户下使用已配置模型完成一次真实三批次简报生成，记录见《验收记录》。

参考：[OpenAI 结构化输出文档](https://developers.openai.com/api/docs/guides/structured-outputs)。

## Word 与 PDF

同一个已保存正文版本用于两种导出。未保存的编辑不会混入导出。通用模板位于 `templates/brief.docx`，使用 A4 页面、黑色中文标题、报告期间、编号章节、仿宋正文及居中页码；只导出报告内容，不附来源、指标总表、生成说明或资料完整性附录。空章节不输出占位说明。模板生成脚本为 `scripts/build_template.py`，导出缓存按模板内容区分，旧简报重新导出也会应用新版排版，历史正文保持原样。

PDF 使用 LibreOffice 转换同一份 Word。程序优先使用设置中的路径，其次 `PM_SOFFICE` 环境变量、本项目 `local/tools/libreoffice/program/soffice.exe`，再查找 PATH。转换时使用独立临时配置目录。缺失组件时返回明确提示，Word 可独立导出。

转换组件取自 [LibreOffice 官方下载](https://www.libreoffice.org/download/)，本项目使用的包及许可保留在 `local/tools` 中；通过管理解包放入项目目录，不设置系统文件关联。移动到其他电脑时可复制该目录或重新配置转换路径。中文字体使用 Windows 自带的宋体、黑体和仿宋。

## 备份与恢复

- 在“设置”中手动创建备份并下载到其他磁盘。
- 应用运行期间，每日首次成功数据变更后自动备份。关闭期间不运行后台计划任务。自动备份保留数量可配置；手动及恢复前备份不自动清理。
- 使用 SQLite Backup API 生成一致副本，ZIP 中包含数据库、已绑定附件和 SHA256 清单。临时上传、API Key、配置和可重建导出缓存不进入备份。
- 恢复前先检查备份日期、数据库版本、项目数、附件校验；输入“替换当前业务数据”明确确认。系统自动生成恢复前备份，再替换业务数据。
- 备份文件放入 `data/backups/` 即可在维护界面中检查及恢复。迁移电脑时先启动空应用，再放入 ZIP 并恢复，不要手动覆盖正在使用的 SQLite 文件。
- 恢复完成后，配置和 API Key 保持本机原值。若恢复内容不符，可选择自动生成的 `before-restore` 备份再恢复。
- 数据目录默认 `data/`，可用 `PM_DATA_DIR` 指定绝对路径。附件使用相对路径，迁移后仍可解析。
- 移除附件只设置可恢复标记，不物理清理被引用文件；取消登记的暂存附件即时清理，异常中断的暂存文件在启动或每日自动备份时按 24 小时规则清理。

## 代码编写

“代码编写”入口位于项目沟通与工作日志之间，按日期、项目功能模块、功能点、主要工作、耗时（分钟）、异常或额外耗时说明登记。日期、模块、功能点、主要工作和耗时必填，异常说明选填；耗时为正整数分钟。支持新增、编辑、修订记录、移除、关键词/模块/日期筛选与分页，归档项目只读，引用停用模块的历史记录保留。代码编写独立登记。
